What's inside

  • site/

    This website, built with Next.js and Tailwind from the free Velora UI template.

  • docs/

    The published website, plus the report tool itself in plain HTML and JavaScript.

  • connect/

    The small Instagram connector, a free Cloudflare Worker that stores nothing.

  • skills/

    Claude Code skills: the Python engine, the AI boardroom and the platform rules.

  • tests/

    Automatic checks for the maths, the connector and every page.

Run your own copy

  1. 1

    Fork it. Press Fork on GitHub. It's free.

  2. 2

    Turn on Pages. Settings, then Pages, then branch main and folder /docs.

  3. 3

    Open your site. Uploads work straight away. For username lookup, follow CONNECT-INSTAGRAM.md.

git clone https://github.com/Siddharthmehdiratta/creator-growth-studio.git
cd creator-growth-studio/docs
python3 -m http.server 8000
